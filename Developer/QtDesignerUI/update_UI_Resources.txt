Update UI And Resource Files
============================

The cross-platform generator is `Developer/update_ui_resources.py`. It generates each
file in a temporary location and replaces the repository target only when the generated
bytes differ. Unchanged targets retain their content and modification time.

Linux:

	Developer/QtDesignerUI/update_UI_Resources.sh

Windows:

	Developer\update_UI_Resources.cmd

Check for stale generated files without updating them:

	python3 Developer/update_ui_resources.py --check

The generator also restores declared generated-file analysis directives, including the
MyPixler page-workflow wizard's narrow Pyright compatibility directive.

Retired generated targets are removed during updates and reported as stale by `--check`.
MyPixler's canonical generated target is:

	ViewController/1-PreProcess/MyPixlerUI.py
